
# MattBread Arcade — Mini Pack 03

Welcome to Mini Pack 03 of MattBread Arcade!

This pack introduces games 21–30. These titles are planned for future playable implementations.

## Game Lineup

21. Cyber Ninja — Dodge traps and defeat enemy bots.
22. Galaxy Defender — Protect your ship from waves of aliens.
23. Crystal Quest — Collect gems and find the exit.
24. Neon Drift — Race through futuristic tracks.
25. Zombie Survival — Survive as long as possible.
26. Tower Stack — Stack moving blocks as high as possible.
27. Frostbite Run — Jump across icy platforms.
28. Dungeon Miner — Dig for treasure while avoiding hazards.
29. Color Clash — Match colors before time runs out.
30. Boss Rush Arena — Battle increasingly difficult bosses.
